# Gertrude task lifecycle

Read `~/.agents/skills/gt-workspaces/SKILL.md` for the shared authoritative
instructions, and `gt --help` for the installed commands. The former
Ghostty/Zellij/Pi task launcher is retired.

gt manages creation, provisioning, and deletion. Rex handles everyday switching;
the user manages their own conversations and layouts. Do not reset databases to
reopen a task. Never finish, discard, or refresh databases without authorization.
